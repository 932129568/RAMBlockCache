## 2. 修复总账（按危害级排序）

### 2.1 数据丢失/损坏级（11 项）

| ID | 缺陷 | 修复 | 验证 |
|---|---|---|---|
| DATA-12 | SET_INFORMATION（删除/改名/截断）前不刷脏——应用自更新簇复用后旧脏覆盖新 DLL | 闸门：簇相关操作前 flush | 构建 ✓ |
| **DATA-15** | **上述闸门只 flush 不丢视图——簇释放复用后读命中旧干净块=读到被删文件内容（0xC0000142 另一半根因）** | **三闸门 flush 后 discard_all** | 构建+套件 ✓ |
| DATA-13 | 离开加速态（Enabled/WriteBack 切换、卷热停用）不丢缓存视图 | 切换点刷脏+丢视图 | ✓ |
| DATA-11 | 关总开关/切直写不刷脏 | 前置 flush | ✓ |
| DATA-14 | FSCTL/IOCTL（TRIM/置零/卸载/收缩/碎片整理）前不刷脏 | 闸门+丢视图 | ✓ |
| F9 系 | flushfile/透传写先失效后直写（直写失败丢唯一副本） | flush-first 范式 ×5 站点 | ✓ |
| R4-Q4 | restoring 恢复窗口 stage 期可把失败写数据持久化 | stage_run 复核+keep 升 dseq | 套件 ✓ |
| R4-Q6 | write-through 分支无 flush-first（模式切换竞态旧脏盖新） | 补同款纪律 | ✓ |

### 2.2 系统稳定级（4 项）

| ID | 缺陷 | 修复 |
|---|---|---|
| **DEADLOCK-1** | **flush 互斥无限自旋（`while(CAS) RB_YIELD` 无上界）——实测 detach 卡 40s+桥接被钉死** | flush_acquire 有界 2s，超时让位（脏留缓存无损） |
| REDTEAM-1 | 我自引的 IRQL 越权（`<=APC` 取 ERESOURCE=蓝屏级） | 收紧 `==PASSIVE` |
| DATA-6/R5 | DETACH 静止判据误判（卡慢盘 worker→流销毁→UAF） | 稳定值 ≤4 收紧 |
| 0x7B-DISTRIB | **首装 BOOT_START 在陌生机器=0x7B 蓝屏循环（对方机器实测）** | **首装改 DEMAND_START（物理不可能 0x7B）+ /BootStart 显式升级开关** |

## 8. 对方机器（0x7B）后续

那台机器当前状态：驱动服务已禁用、文件已删、UpperFilters 干净——**系统已恢复正常**。重新安装用桌面新包即可，流程：

```
双击 Setup → UAC → 向导 →（根证书自动导入）→（testsigning 自动开，
若 360 拦截会显示具体原因——退出 360 后点重试）→ 重启 → 桌面快捷方式即用
```

首装 DEMAND_START 后驱动**不参与引导**（不可能 0x7B）；确认稳定运行后，如需开机自动挂载，管理员 CMD 执行：
```
sc config RAMBlockCache start= boot
```
再重启一次即升级为 BOOT_START。
