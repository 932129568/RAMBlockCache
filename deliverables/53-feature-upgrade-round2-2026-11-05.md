## 1. 本轮升级项

### 1.1 诊断页·日志工作区【用户明确要求】

**问题**：驱动日志已由桥接落盘到 `%ProgramData%\RAMBlockCache\logs\`，但用户/支持人员无法直接访问——故障复盘仍要手工找路径。

**升级（桥接 3 条路由 + 诊断页 1 个工作区）**：

| 层 | 内容 |
|---|---|
| 桥接路由 | `GET /rb/logs`（文件列表）· `GET /rb/logs/:name`（尾部 512KB 内容）· `POST /rb/logs/open`（资源管理器打开目录） |
| 安全 | 文件名白名单正则 `^driver-\d{8}\.log(\.\d)?$`——**绝不拼接用户输入路径**（防目录穿越）；仅监听 127.0.0.1 |
| 诊断页 | ①「打开日志目录」按钮（表头）②落盘历史文件列表（含大小，10s 刷新）③点击文件名展开内容预览（等宽、可滚动、超 512KB 显式提示截断） |
| 统一路径 | `LOG_DIR` 常量被 log-sink 与路由共用，避免两处硬编码漂移 |

**用户价值**：0x7B 这类崩溃复盘时，重启后仍能回看**崩溃前的完整驱动日志**（512 条 × 96 字符持久化），且一次点击即可定位。

### 1.2 桥接进程容错【健壮性】

**问题（严重）**：桥接**完全没有进程级异常处理**——`unhandledRejection` 会让 Node 静默退出，表现为"控制台突然失联"，此前无从归因。

**升级**：
- `unhandledRejection` / `uncaughtException`：**记录后继续服务**（绝不因单次异常丢失整个控制面）
- `SIGINT` / `SIGTERM`：有序关闭（停日志落盘 → 关设备句柄 → 退出）

### 1.3 卷页信息降噪【UX 修复】

**问题**：`FreeMB` 恒为 0（块层过滤器无文件系统语义，拿不到剩余空间），界面却显示"可用 0 MB"——**会被误读为"磁盘已满"**，用户可能因此放弃加速。

**升级**：改为显式 `可用 —` 并加悬浮说明（"块层过滤器无文件系统语义"）；容量值加粗强调；开关/扇区信息分组降噪。
