### 2.3 方向是否稳定（明确回答）

- **中位数口径**：严格单调下降 `1 > 2 > 4 > 8 > 16`（1216.89 / 894.86 / 698.15 / 427.80 / 247.50），与 72 号 rep1 方向一致，与中午 63 号「2 路最高、1 路次低」**低端翻转**。
- **逐轮口径**：1 路为当轮最高 **8/12**；16 路为当轮最低 **11/12**（唯一例外 r7 因 16 路全空、样本缺失导致 8 路成为数值最低，属器具伪影）；五档严格单调仅 **5/12**（r1/r3/r4/r8/r12）。
- **离散度 63.5–97.5%**，叠加 `[empty-zone]`：方向**不够稳定**。
- **跨批次唯一可复现的方向**：「**16 路最低**」——中午 63 号（140.5 最低）、72 号 rep1/rep2、本批中位数与 11/12 逐轮均成立。中午「2 路最高」本批未复现。
- **结论**：**不给最优路数结论**；只记录「同条件下 1 路相对最高、16 路相对最低」这一粗趋势，且明确其受短窗口空路噪声主导（63 号 §5.1 纪律）。

### 3.4 明确回答用户两问

1. **「Verifier 关闭后 16K 是否仍为拐点」**：**中位数口径下是**（16K 73.65 GB/s，为四几何最高；4K→8K→16K 递增）。**但拐点「不稳定」**：16K 与 8K 的排序在 **3/7 轮翻转**（r5 明确、r6/r7 边际），16K 离散度 **36.4%** 且呈明显**双簇**（r1–r3 ≈ 93 GB/s，r4–r7 ≈ 66.7–73.7 GB/s），疑似 CPU 频率/温度/调度状态切换。因此**只能说「16K 在中位数口径仍是相对高点」，不能宣称「16K 稳定最优几何」**；62 号要求的「可信基准条件（空闲多轮中位 + 真机端到端）」仍只满足前者的一半。
2. **「32K 陡降是否复现」**：**7/7 轮复现，方向稳健**。32K 在全部 7 轮均为四几何最低（40.43–50.63 GB/s），`32K/16K = 0.52–0.64`（中位 0.62×，62 号 0.57×），`32K/4K = 0.87×`（62 号 1.00×）。**这是本批最稳健的几何结论**，但仍属用户态 core 微基准的相对趋势，不外推到真机。

## 6. 口径限制（明确章节，不得省略）

1. **用户态内存模拟盘 memcpy，无真实块设备时延**：`test_flushpar` 的 `thr` 与 `bench_readhit` 的 `GB/s` 都只衡量 core 引擎的用户态 memcpy + 锁开销，**不是**盘/驱动/整机吞吐。63 号 §5.1 已定性：「窗口仅 16×260KB、单组合 3–80ms、短窗口下 lane 可能空转、噪声主导，绝对值不作峰值宣称、不据此给最优路数结论」。
2. **电源计划与用户自述并列**：`powercfg` 实测仍「平衡」，用户自述「性能模式」。两条并列如实记录，**不擅自把任何数字称作「真机峰值」或「最佳性能档」**。Verifier 已关是事实，但不能据此把绝对提升当作性能结论。
3. **与 62 号不同 env，绝对值不可比**：62 号是安静模式 + Verifier 开，本批 Verifier 关但 `powercfg` 仍平衡。本批 GB/s 为 62 号的 2.45–3.03×，**只反映环境/开销变化，不是产品性能提升量**；对比仅限**相对形状**（拐点、陡降、比值）。
4. **跨几何 MB/s / GB/s 不可直接比较效率**：`bench_readhit` 的 `GB/s = bs/ns/op`，几何变大天然抬高每 ns 搬运字节数；`test_flushpar` 的 `thr` 也随几何放大回写量（72 号 §8.1）。不同几何的数字**不能**读作「哪个几何更快」。本单 S2 比较的是同一公式下的**形状/拐点**，不是效率排序。
5. **`test_flushpar` 代表性 `thr` 有采样偏差**：取 `concurrent/full/write-back` 非空 lane 均值；空 lane 越多样本越少、均值越易偏高（16 路 r7 甚至全空无样本）。已如实排除，不补值。
6. **真机端到端未覆盖**：按派单硬边界，本轮**未**做真机 detach/attach、**未**改 `BlockSize`、**未**切回写、**未**碰 D: 卷。73 号 §7 / `KNOWN_ISSUES` H8 的「内核侧 >4K 非对齐写 + 并发驱逐真机验证」仍为**未覆盖项**，需另起 WDK/Verifier 周期。用户原话中的「端到端」在本单只落实为「用户态 core 端到端的两条基准链」，**不是真机端到端**，此处如实披露。
7. **不给最优结论**：五路「1 路最高、16 路最低」只是同条件粗趋势，离散度 63.5–97.5%、逐轮稳定性 8/12 与 11/12；16K 拐点也只是中位数口径，16K 与 8K 排序 3/7 轮翻转。**均不用于选最优路数/最优几何**。
8. **数字不可复用**：72 号 >4K 性能矩阵已按 73 号 §7 归档为「已知缺陷阻塞、数字不可采信」，本单**未复用**其中任何数字。
