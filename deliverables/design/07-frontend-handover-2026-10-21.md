## 1. 设计思路

### 1.1 为什么是"增量重构"而不是"推倒重来"

V2 暗色精密仪表体系（8 层背景/语义五色/图表 9 色/六档动效）已在 10-19~10-20 完成六页 1:1 WPF 落地并通过真机冒烟。V10.6 的需求（来自 PRD《内存缓存软件公开调研与迭代方案》）全部是**功能面新增**（场景预设/二遍读对比/回写引导/反作弊检测/许可试用），不是视觉方向变更。因此本版设计策略 = **V2 骨架不动、令牌纪律不破、新增七个组件面**——PRD 说的"符合主流审美"通过层次精度与微质感增量满足（§1.3），不做特效堆砌。这样做的工程收益：WPF 侧零回归风险，新功能面直接在既有令牌上建设。

### 1.2 设计五要素（Phase 1 结论）

| 维度 | 结论 |
|------|------|
| 场景 | WPF 桌面控制台（1180×780，min 900×600）+ 首次向导（扩五步）+ 托盘 + 弹窗体系（新增两种范式）+ 状态条四段；驱动侧零改动 |
| 受众 | 数据盘三类用户（游戏玩家/仓库盘用户/性价比装机者）+ 非技术用户（PRD 验收标准"3 分钟完成首配" → 预设与向导零术语） |
| 调性 | 暗色精密仪表 2.0：V2/Linear 骨架 + 层次精度与微质感增量；受众共同刚需是"确定感"——要精确，不要惊艳 |
| 品牌 | 无外部品牌；青色 `#4CC2FF` 自有身份不变，不引入第二品牌色 |
| 规模 | 六页重构（令牌一致性）+ 4 新功能面 + 1 状态展示面 + 向导增强 + 弹窗体系扩展 + 演示态 8→12 |

### 1.3 视觉/动效增量（V-1~V-7，全部落在既有令牌与禁令框架内）

| # | 增量 | 落地 |
|---|------|------|

| V-2 | 图表质感 | 折线/条形圆角线帽（WPF `StrokeLineCap=Round`）；热力格 2px 圆角（组件常量）；面积维持单色 12% α |

### 2.2 跨功能面公共契约

- **操作进度事件（#17）**：F2 基准运行、F1 多卷预设应用、卸载回写、L2 重建共用同一事件结构；前端统一渲染「进度条 + 阶段文案 + 取消（若 cancelable）」。原型已按此实现（250ms 节流 ≤4Hz）。
- **错误码与三段式归因**：所有失败沿用三段式异常卡结构（发生了什么/影响与风险/如何撤销）；新功能面不发明新错误范式。
- **双栏日志**：F3 选择记录、F4 检测结果、F2 基准结果摘要均写 UI 日志，诊断包导出可见（与驱动日志同屏对照）。
- **遥测同口径（I-02）**：F2 基准采样口径与 CLI 完全一致；默认关、一键可关。

### 3.2 组件状态机（前端必须实现的三态 + 交互态）

- **所有新组件**：空态/加载（shimmer 骨架）/降级（能力不可用时 warning 横幅 + 明示原因）三态齐全——这是评审 P1 修正项，WPF 移植时直接按原型实现，勿省。

- **C-4 对话框**：DetectingPower（400ms）→ ShowingAdvisory →（勾选）→ Applying → Applied/Cancelled；**Esc/遮罩 = 取消（与取消按钮同收敛函数，settled 标志位防双触发，Applying 后不回滚）**；低电量 = 确认禁用（原因优先于未勾选）。

## 4. 注意事项（移植与协作纪律）

### 4.1 硬纪律（违反即返工）

1. **动效单一事实源**：所有时长/缓动/缩放走 `Controls/Motion.cs`；XAML 零 `0:0:0.` 字面量（V2 铁律，V3 延续）。
2. **色值零字面量**：全部走 `Theme/Dark.xaml`；V3 仅新增 3 令牌（N-1 DurStagger 24ms / N-2 ScaleOverlayFrom 0.98 / N-3 PresetTierBarWidth 3px）+ 1 组件常量（RbcHeatCellRadius 2px）。
3. **禁布局属性动画**：只动 transform/opacity（scaleX/scaleY + origin）；进度/生长/装载全部 transform 范式（Round 1 红线 6 一票否决项的教训：`.cw-fill` width 过渡已改 scaleY）。
4. **reduced-motion 全分支**：新组件一个不漏（对话框 0ms 直关/条形终态直显/骨架停止流光/阶梯全量直显）。
5. **话术纪律（I-08）**：禁「秒变 SSD/飞速/极大提升/效率翻倍/提升 N%」；术语白名单（挂栈/加速/直写/回写/熔断/安全模式/命中率/未落盘数据）；性能表述必须可复现（= F2 工具口径）。原型禁用语 grep 零命中——WPF 移植后复扫保持为零。
6. **数据诚实性硬门**：F2 对比不过 Windows 文件缓存 = 假对比；与 CLI 口径漂移 >2% 不得发布（写入发版门禁）；未接通执行体前，界面只显示降级横幅，不显示 mock 结果。
7. **禁用态必须配原因副文本**；危险按钮不做默认焦点（打开时焦点落取消）；Esc/遮罩 = 取消（C-4 教训：关闭路径必须与取消按钮同收敛，否则=未经同意开启回写）。

### 4.2 原型专用物——**不进 XAML**（严过审 N-2 裁决的剥离清单）

- 标题栏**演示态下拉**（12 态走查器）——原型专用；
- 四处卡底**演示开关**（`<details>`：对比卡降级横幅开关/预设卡/许可卡/缓存策略卡电源五态 select）——原型专用，上线前剥离；
- 原型 src-tag 灰色小字母角标——**不等于** WPF 的 LinkChip（产品化联调角标，默认开、设置页可关）；移植时按 LinkChip 体系做，勿照搬 src-tag 样式；
- README §6 已同步记录本清单。

### 4.3 其他协作注意

- **契约冻结节奏**：F2 执行体契约（#5/#6/#7/#8）必须 W1 内与后端冻结；UI 可先按契约建、执行体随后端波次接通（src-tag/LinkChip 标注 + 演示态兜底）。
- **预设不覆写项**：每卷配额/挂载状态/自定义排除名单永不被预设覆写（配额与磁盘容量强相关，属用户个体决策）；全局内存预算未确认（🔶）前不覆写并标"协议待确认"。
- **许可天数口径**：remainingDays 计算方式（自然日/24h 滚动）需双方冻结后实现，避免前后端差一天。
- **彩格调文档回写**（06 文档三处，进行中）：C-4 标题白名单表追随实现、V-3 补记 translateY 分量、V2 遗留两项登记。
