## A. 数据可视化规范

### A.1 图表清单与选型

> 数据来源：`RB_STATS`（消息 1）、`RB_VOLUMES`（消息 7）、IOCTL 通道调用结果。所有图表数据**必须来自 §C 单一状态对象**，禁止各图独立请求（对齐 RA.2）。

| # | 图表 | 用途 | 类型 | 数据来源字段 | 坐标 / 单位 | 尺寸（DIP） | 空数据表现 | 异常数据表现 |
|---|------|------|------|--------------|-------------|-------------|-----------|--------------|
| 1 | **读命中率趋势** | 让用户"看见价值"（首页/收益页） | 折线 + 面积 | `HitRate` 滚动窗口，最近 5 分钟 / 60 采样点（5s 一点） | Y 轴 0–100%，仅左轴 3 刻度（0/50/100）；X 轴仅"5 分钟前 / 现在"两端标签 | 宽 ≥480 × 高 160 | 显示"统计暂不可用（原因）"占位，不画归零线 | 采样中断处**断线留缺口**（gap），不插值、不归零 |
| 2 | **缓存占用与上限** | 一眼看懂"用满没有" | **环形进度**（见选型理由） | `CacheUsedBytes` / `CacheCapBytes` | 比例 0–100%，中心大数字 | 160 × 160（环 stroke 10px） | 环轨道全灰 + 中心"—" | 超限时环变琥珀并加"已超限"标签 |
| 3 | **读写吞吐** | 对比读/写速率 | 双线（趋势）或双条（当前值） | `ReadBytesPerSec` / `WriteBytesPerSec` | Y 轴 0–自适应，单位 MB/s | 宽 ≥480 × 高 140 | 同 #1 | 同 #1（断线） |
| 4 | **64 分片吞吐** | 定位热点分片 | 迷你热力条（64 格，3 档色阶） | `Stripe[64].Throughput` | 每格归一化到当期最大值的 33% / 66% 分档 | 每格 4 × 24，间隔 2 → 总宽 384 × 高 24 | 全格置灰（`--rbc-bg-skeleton`） | 单格异常（值为 0 且有压力）标红描边 |
| 5 | **未落盘数据量** | 风险可见（状态条风险段 / 应急页） | 堆叠水平条 | `DirtyBytes`（未落盘）/ `LostDirtyBytes`（已确认丢失） | 相对缓存上限的百分比 + 绝对值 | 宽 100% × 高 10 | 显示"—"，不显示 0 长度条 | `LostDirtyBytes>0` 时红段出现 + 琥珀描边 |
| 6 | **IOCTL 通道健康** | 联调归因（诊断页） | 状态点阵 + 延迟迷你条 | 12 条消息调用结果 / 延迟 | 点阵 12 格，每格延迟归一化 | 每格 24 × 24，间隔 4 | 未接通格为灰点 + "—" | 降级琥珀点 / 不可用红点（对齐 §C.2） |
| 7 | **写模式构成** | 一眼看懂"几卷直写/回写" | 分段水平条 | 卷数按 `WriteMode` 分组 | 段宽 = 卷数占比 | 宽 100% × 高 10 | 无卷时整条灰 + "尚未加速任何卷" | 回写段出现时右侧附琥珀警示角标 |

#### 选型理由（#2 环形 vs 水平条）

**选环形进度**，理由：
1. **单值对容量**语义天然适合环形（"满没满"一眼可读），且环心可承载大数字 + 单位，符合"大数字 + 迷你图"的 bento 卡范式。
2. 与首页三数字卡的"圆形/方形点缀"形成节奏对比，视觉更"有美感"（用户要求）。
3. 无需坐标轴，占用面积小，适合并排 bento 网格。
4. 备选水平条仅用于"每卷容量占比"这类**多行并列**场景（一行一卷时水平条更易横向对比）。

### A.4 数字与单位格式

| 规则 | 定义 | 示例 |
|------|------|------|
| 字节自适应 | 自动选择 KB / MB / GB / TB | `620 MB` / `3.2 GB` / `31.4 GB` |
| 小数位 | KB/MB → 0 位；GB/TB → 1 位 | `620 MB`、`3.2 GB` |

| 千分位 | 计数类 ≥1000 加千分位 | `12,480` |
| 超限缩略 | ≥9999 用 K/M 缩略（1 位小数） | `12.5K`、`3.4M` |
| 数字字体 | 一律等宽栈 + `font-variant-numeric: tabular-nums`（防每秒刷新抖动） | — |

| 态 | 表现 |
|----|------|

## B. 动效规范

### B.1 时长与缓动令牌

**时长（3 档 + 2 扩展）**：

| Token | Value | 用途 |
|-------|-------|------|
| `--dur-instant` | 90ms | 焦点环、按钮按下反馈 |
| `--dur-fast` | 120ms | 卡片 hover、颜色切换（小元素） |
| `--dur-base` | 180ms | 状态色切换、Toast 进出、弹窗、列表增删（**标准档**） |
| `--dur-slow` | 240ms | 页面入场、卡片抬升 |
| `--dur-slower` | 480ms | 图表一次性描边入场（唯一 >240ms 的常规动效） |

**缓动（1 条标准曲线 + 3 辅助）**：

| Token | Value | 用途 |
|-------|-------|------|
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | **默认曲线**（进出对称，用于状态/尺寸切换） |
| `--ease-out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场（减速） |
| `--ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | 出场（加速） |
| `--ease-linear` | `linear` | shimmer / 不确定进度条（循环） |

> **禁止**：`ease-in-out` 之外的弹跳/弹簧/过冲曲线（`bounce`、`elastic`、`back`、`spring`）。

### B.2 逐项动效参数表

| 场景 | 时长 | 缓动 | 属性 | 说明 |
|------|------|------|------|------|
| 页面入场 | 240ms | `--ease-out` | opacity 0→1 + `translateY(8px→0)` | 切换页面时 |
| 卡片 hover | 120ms | `--ease-standard` | `translateY(0→-1px)` + 背景 `surface→surface-hover` + 描边 `subtle→default` | **覆盖 v1.0 §B.4.3**"hover 不改描边"：为满足"特效完善 + 有美感"，允许 hover 抬升 1px 并微亮描边（仍无阴影） |
| 状态色切换 | 180ms | `--ease-standard` | background-color / border-color / color | 徽标、状态条段 |
| 数字滚动 | 320ms | `--ease-out` | 数值插值（rAF 逐帧） | 统计刷新时数值从旧值滚到新值 |
| 图表描边入场 | 480ms | `--ease-out` | `stroke-dashoffset` | **仅首次渲染**，一次性；刷新不再播 |
| 骨架 shimmer | 1400ms | `--ease-linear` | `background-position` 0→200% | 循环；单色（见 §B.3-8） |
| Toast 进场 | 180ms | `--ease-out` | opacity 0→1 + `translateY(8px→0)` | 出场 120ms `--ease-in` |
| 进度条·确定态 | 180ms | `--ease-standard` | `transform: scaleX()` | 用 transform 不用 width |
| 进度条·不确定态 | 1200ms | `--ease-in-out` | `translateX` 往复 | 40% 宽条往复 |
| 弹窗进场 | 180ms | `--ease-out` | opacity + `translateY(8px→0)` | 遮罩 opacity 120ms；**禁缩放弹跳** |
| 列表增删 | 180ms | `--ease-standard` | FLIP（transform + opacity） | 不直接动 height（避免 layout thrash） |
| 状态点脉冲 | 1200ms | `--ease-in-out` | opacity 1→0.45→1 | **周期 ≤2s**（合规）；仅"熔断·自愈中""正在重连"使用 |

### B.3 允许的特效清单（可用规范，含参数）

1. **面积图单色低透明度填充**：`--chart-area-fill` = `rgba(76,194,255,0.12)`，单色，**非渐变**。
2. **状态点脉冲**：1200ms 循环，opacity 1↔0.45，`--ease-in-out`；仅用于"进行中"状态（自愈中 / 重连中）。周期 ≤2s。
3. **卡片 hover 抬升**：`translateY(-1px)` + 描边微亮，120ms `--ease-standard`（见 §B.2）。
4. **按钮按下位移**：`translateY(1px)`，90ms，释放回弹 120ms（**非弹跳**，线性回位）。
5. **数字滚动计数**：320ms `--ease-out`，rAF 插值；数值变化时启用，静态刷新不重播。
6. **图表一次性描边动画**：480ms `stroke-dashoffset`，仅首帧；后续数据更新为直接位移。
7. **页面切换淡入 + 8px 位移**：240ms `--ease-out`。
8. **骨架 shimmer**：**单色**高光扫过——底 `--rbc-bg-skeleton`，高光 `#26262E`，1400ms `--ease-linear` 循环；**覆盖 v1.0 §B.4.9**（原规定"禁用渐变扫光、用透明度呼吸"）：为满足"特效完善 + 行业标准"，允许**单色低对比** shimmer 扫光（非多彩渐变），仍禁高对比/多彩扫光。
9. **Toast 进出场**：进 180ms / 出 120ms，位移 8px。
10. **进度条不确定态**：40% 宽条 1200ms 往复。
11. **焦点环**：`--rbc-focus-ring` 2px 外环，90ms opacity 淡入，**始终可见**（可访问性）。

### B.4 禁止清单（Anti-Slop 边界）

> 与 v1.0 §F.2 一致，并新增 4 条特效禁令。

1. ❌ **玻璃拟态 / 毛玻璃**（`backdrop-filter: blur`）。
2. ❌ **霓虹发光**（`box-shadow` 光晕、`text-shadow` 发光）。
3. ❌ **多彩渐变文字**（`background-clip:text` 渐变）。
4. ❌ **视差滚动**。
5. ❌ **装饰性粒子 / 彩带 / confetti / 撒花**。
6. ❌ **弹跳缓动**（bounce / elastic / spring / back 过冲）。
7. ❌ **超过 2 档字重**（仅 400 / 600）。
8. ❌ **无意义阴影**（卡片重投影、发光代替结构）。
9. ❌ **emoji** 出现在界面（图标一律线性矢量）。
10. ❌ **纯装饰、无信息量的动效**（如标题逐字弹入、图标旋转、背景呼吸装饰）。
11. ❌ **动效阻塞交互**（动画期间禁止用户操作）。
12. ❌ **循环动效超过 2s 周期**（脉冲/呼吸类）。
13. ❌ **动画 `width`/`height`/`top`/`left`/`margin`**（一律用 `transform`/`opacity`）。

### B.5 性能与可访问性约束

**性能**：
- **只动 `transform` 与 `opacity`**（合成层友好）；进度条用 `scaleX` 不用 `width`；列表增删用 FLIP。
- **避免 layout thrash**：读取布局属性与写入分离；批量在 rAF 内提交。
- **目标 60fps**：单帧 JS 主线程工作 <8ms；图表重绘限流 ≤ 每 1s 一次（对齐 1s 轮询）。
- 图表首帧描边动画与数据刷新解耦（避免每秒重播）。

**可访问性 —— `prefers-reduced-motion` 全量降级规则**：

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
  /* 位移一律归零 */
  .page-enter, .card-hover, .btn-press { transform: none !important; }
  /* 脉冲 → 静态点（保留状态色） */
  .status-dot--pulse { animation: none !important; opacity: 1 !important; }
  /* shimmer → 静态骨架（保留占位结构） */
  .skeleton { animation: none !important; background: var(--rbc-bg-skeleton) !important; }
  /* 进度条不确定态 → 静态 40% + 文案 */
  .progress--indeterminate .bar { animation: none !important; transform: scaleX(.4) !important; }
  /* 数字滚动 → 直接显示终值（由 JS 检测 media query 关闭插值） */
}
```

**降级后信息不丢**（硬要求）：
- 状态语义 100% 由**颜色 + 文案**承载，不依赖动效（脉冲仅"加强"，不是唯一表达）。
- 骨架屏静态仍占位，加载文案"正在读取驱动状态…"始终显示。
- 进度条不确定态降级后仍显示静态条 + "正在…"文案。
- 图表描边降级后**直接全显**，数据完整可读。
- 所有数值、单位、断线缺口在降级后保持不变。
