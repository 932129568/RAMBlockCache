## §1 增量总览

### 1.1 新增令牌（预估 3 项）

> 原则：**无跨组件复用消费方的值不下沉为令牌**，只作组件常量记录在组件规范内。因此 V3.0 新增令牌极少——这本身就是纪律成果。

| # | 令牌 | 值 | 类型 | 消费方 | 新增理由 |
|---|------|----|------|--------|----------|
| N-1 | `RbcDurStagger` | 24 ms | 时长 | V-6 卷卡列表首次装载阶梯淡入（≤5 项） | 六档时长（90/120/180/320/480/1200）语义均为「一次过渡」；装载阶梯是「逐项间隔」新语义，混用会破坏 Motion.cs 可读性；5 项总跨度 ≤96ms，落在 Dur120 感知档内 |
| N-2 | `RbcScaleOverlayFrom` | 0.98 | 缩放 | V-3 浮层微入场（C-4/C-5 对话框、下拉、浮层共用） | 入场缩放起点必须全局一致（0.98→1 配 Dur180 + EaseOut）；写成常量防止各处字面量漂移；禁弹跳（红线 9） |
| N-3 | `RbcPresetTierBarWidth` | 3 px | 度量 | C-1 三档语义条 | 档位标识条宽度；非间距体系成员（间距为布局值、4 的倍数），单列度量常量避免与 spacing 体系混淆 |

> C-5~C-7 预估不新增令牌（下一批冻结；若反作弊警示框、许可卡或进度横幅确需新值，按「跨组件复用」原则裁决，预估增量 ≤ +1）。

### 1.2 修订令牌（0 项）

V3.0 **纯增量**：无修订、无删除、无重命名。以下三项在需求 / 评审中被讨论过，裁定为**不修订**：

| 曾被讨论的「修订」 | 裁定 | 理由 |
|--------------------|------|------|
| A-3 主按钮色（#185FA5 → #4CC2FF 拍板） | 不修订 | V2 `RbcAccent` 已定义为规范青 #4CC2FF；拍板结论 = 存量误用改正，非令牌变更（D-10 已裁） |
| V-4「KPI 大值仅主指标用 accent」 | 不修订 | 这是**组件层用色规则**（哪个指标算主指标），不是令牌值问题；令牌不动，规则写入 C-3 等组件规范 |
| F2 双条形第一遍用色（05 原文 RbcChart2） | 不修订 | 同为**组件层消费决策**：C-3 裁定第一遍 = `RbcNeutralFg`、第二遍 = `RbcChart1`（见 C-3.3 偏差说明）；图表令牌本身不动 |

### 1.4 增量四原则

1. **复用优先**：组件能用 V2 令牌拼出来的，不建新令牌。
2. **零新增色值**：任何新颜色须先过 WCAG（相对亮度手算 + 假设底标注）再报主理人裁定；本批不需要。
3. **动效单一事实源**：时长 / 缓动 / 缩放全走 `Controls/Motion.cs`，XAML 零字面量。
4. **组件常量不下沉**：仅跨组件复用的度量才升为令牌（N-1~N-3 即按此裁决）。

## §2 新组件规范（C-1~C-7）

### 2.0 通用约定（适用于全部组件）

1. **tertiary 纪律（红线 7）**：11px 小字若承载信息（口径声明、免责、说明、禁用原因），必须用 `RbcTextSecondary`；`RbcTextTertiary` 仅允许 ≥24px 或非信息装饰。本批所有 11px 文本一律按 secondary 执行。
2. **数字纪律（红线 8）**：等宽栈、数值与单位分排、不可用显示「—」禁显 0。
3. **文案纪律（I-08）**：术语白名单 = 挂栈 / 加速 / 直写 / 回写 / 熔断 / 安全模式 / 命中率 / 未落盘数据；禁「秒变 SSD」类不可复现表述；冷热口径全 App 统一为「第一遍 = 盘速 / 第二遍 = 缓存速」。
4. **三态齐全**：每个组件必须同时给出空态 / 加载 / reduced-motion 降级（V10.6 评审会逐项查）。
5. **图标**：一律线性矢量；界面零 emoji（红线 11）。
6. **待补测项（本批唯一）**：C-3 双条形第一遍以 `RbcNeutralFg` 作填充——该「填充 × 表面」组合 V2 未实测；二者同属 V2 中性阶，推定非文本对比 ≥3:1（WCAG 1.4.11）；下批 §4 令牌表按 04b 实测值补测确认，补测不通过则替换为 `RbcChart2`（05 原方案）。

#### C-1.5 空态 / 加载 / reduced-motion 降级

- **加载**（首开 / 读配置）：卡骨架 shimmer（1400ms linear，V2 特许）：卡头 + 选择行 + 摘要表 3 行；ComboBox disabled。
- **空态 / 降级**（服务未返回预设态）：内容区 24px 线性图标 +「预设状态不可用，请检查服务连接」13px secondary +「重试」次按钮；ComboBox disabled；语义条不渲染。
- **reduced-motion**：数字滚动直显（Dur320→0）；不确定进度脉冲静止为静态 30% 宽条 + 「正在应用预设…」文案常在；Toast / 轻确认直显；骨架流光停止（静态 RbcBgSkeleton 底）。

#### C-1.6 三档语义条合规裁定（R-1，评审必读）

**结论：合规。** 三档语义条是「档位标识（产品配置身份）」，不是「状态表达」，不违反红线 5（禁 accent 表达状态）。理由五条：

1. **范畴不同**：红线 5 禁的是用 accent 表达**系统运行状态 / 健康度**——状态的唯一出口是 `UiStateView.ColorKey`，其数据来自运行时采样。预设档位是用户主动选择的配置身份，不来自状态采样、不随时间演变，不属于「状态」范畴。
2. **accent 用途边界内**：V2 允许 accent 表达「可交互 / 主指标 / 品牌身份」。均衡档 = 产品默认推荐档 = **品牌默认身份**，用 accent 标识「这是默认推荐」在边界内。
3. **三档语义分工正确**：安全 = info（稳健提示）、性能 = warning（性能换风险的警示，与 F3 回写风险语言同色系——warning 表达「此档涉及需确认的风险」正是语义色的正当用途）；accent 不承担任何警示职能。
4. **静态且唯一**：该条只在切档时变色，运行期恒定；卡内无第二个 accent 元素（ComboBox 聚焦框除外），不构成 V-4 所禁的「满屏青色」。
5. **风险备案**：若评审仍判不合规，退化方案 = 三档条统一 `RbcBorderStrong`，档位语义改由线性图标承载（安全 = 盾牌 / 均衡 = 天平 / 性能 = 闪电，16px，RbcTextSecondary），accent 仅保留 ComboBox 聚焦态。

### 4.4 第一批遗留待补测项：实测结论

**待测项**：C-3 双条形第一遍 `RbcNeutralFg` 作填充 × 卡底 `RbcBgSurface` 的非文本对比度（WCAG 1.4.11，要求 ≥3:1）。

**假设底声明**：本批阅读纪律限定只参考 05 与第一批，未读 04b 原文；下列 HEX 为按 V2 暗色阶梯量级的**假设值，以 04b 实测值为准**代入复核。

| 角色 | 假设 HEX | 量级依据 |
|------|----------|-----------|
| RbcBgSurface | `#1E1E24` | 8 层第 4 层（卡片），位于 app 与 hover 之间，与 shimmer 暗端 `#1B1B21` 同量级 |
| RbcNeutralFg | `#9B9BA6` | 语义 neutral 三件套的 fg（中性前景灰），次级文本量级 |

**公式**：`c_lin = c/12.92（c ≤ 0.03928）否则 ((c+0.055)/1.055)^2.4`；`L = 0.2126R + 0.7152G + 0.0722B`；`对比度 = (L_亮 + 0.05)/(L_暗 + 0.05)`。

**手算过程**：

- `#1E1E24`：R=G=30/255=0.1176 → (0.1636)^2.4 ≈ 0.01297；B=36/255=0.1412 → (0.1860)^2.4 ≈ 0.01761；L = 0.01297×0.9278 + 0.0722×0.01761 ≈ **0.01330**
- `#9B9BA6`：R=G=155/255=0.6078 → (0.6281)^2.4 ≈ 0.32752；B=166/255=0.6510 → (0.6694)^2.4 ≈ 0.38147；L = 0.32752×0.9278 + 0.0722×0.38147 ≈ **0.33143**
- 对比度 = (0.33143+0.05)/(0.01330+0.05) ≈ **6.03 : 1 ≥ 3 : 1 → 通过**

**区间扫描**（防单点假设偶然性）：surface 取 `#1E1E24`~`#26262E`（shimmer 亮端）× neutral fg 取 `#8A8A95`~`#9B9BA6`，对比度区间 **4.9 : 1 ~ 6.0 : 1**，全部通过。

**结论**：假设区间内通过（余量 ≥1.6 倍），**保留 C-3 原裁定（第一遍 RbcNeutralFg）**，不退化为 RbcChart2。

**复核判据（交接给实现期）**：以 04b 实测 HEX 代入上式；仅当实测对比度 <3:1（发生条件 = neutral fg 显著偏暗 **或** surface 显著偏亮）时，执行 C-3.3 已记录退化路径：第一遍条形换 `RbcChart2` 并同步修订 C-3.3 偏差说明；该替换同时消除本待测项（RbcChart2 × surface 属 04b 图表色已实测范围）。
