## 2. 本轮新修复的缺陷（均为首次装机才暴露的潜伏缺陷）

| # | 缺陷 | 根因 | 修复 |
|---|---|---|---|
| 1 | **覆盖安装必失败**：`ControlService(STOP)` err=1052 | BOOT_START 卷过滤驱动不注册 `SERVICE_ACCEPT_STOP`，运行期必然拒绝 STOP——设计如此，旧代码当致命错误 | 识别 1052 → 运行期摘卷重试 → 仍失败则 `g_RebootReplaceNeeded`，拷驱动走 `MoveFileEx(DELAY_UNTIL_REBOOT)`（绝不动活映像，0x7B 安全） |
| 2 | 与 #1 矛盾的第二道守卫：服务 RUNNING 就拒拷 | 与 #1 降级路径冲突形成死锁 | RUNNING 时不再拒拷，排队重启替换 |
| 3 | **controller/webconsole 从未落地**：zip 先删后查=必然跳过 | `File.Delete(zipPath)` 后又 `File.Exists(zipPath)` 判缺失 → 跳过解压。每次安装都触发，只有查目录才可见 | 顺序改为「确认存在 → 解压 → 最后删」 |
| 4 | **桥接起不来**：`Cannot find package '@hono/node-server'` | webconsole.zip 只拷了 bridge 源码，运行依赖在仓库 `web\node_modules` 靠向上解析；独立目录无依赖可解析 | build_setup 构建期自动闭包遍历（16 包：hono/@hono/pino/zod+传递），拷入 `webconsole\node_modules\`；不硬编码名单，永不漂移 |
| 5 | WBCOAL 永远开不起来 | `Rb2ReloadFlags` 仍有「未接线强制剥离」（100 批已接线，代码未同步） | 改 `#if !RB_WIRED_WBCOAL` 条件化 + WBCOAL/L2 运行时互斥（第二道防线） |
| 6 | 延迟卡「未采样」但 P50 显示 1 | `us==0`（亚微秒样本）撞 EWMA 的「无样本=0」哨兵；直方图桶 0 又+1 → 自相矛盾 | 亚微秒钳 1µs；「未采样」文案说明 1/64 抽样率 |
| 7 | 验收看 F: 假 FAIL | 脚本硬编码「只允许 D:」 | 基线化：以验收起点卷集合为基线，只查验收期零漂移（保留挂载泄漏保护） |

另：安装界面「测试模式」勾选框已移除（`TestMode` 零残留，安装恒走生产 BOOT_START）；`verify_final_reboot` 已改为基线对齐并 **实跑 PASS**。
