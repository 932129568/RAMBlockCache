| C2-8 | 全部 Bound 未 Attached | `就绪` 蓝 | ☐ |

| **通过标准** | 9 种组合下三处文案一致，且与 `UiStateView.Resolve` 单一出口一致（代码走查：View 层无散落判定） | | ☐ |

## C3 · 错误码映射完备（关联 T2/T3）

| # | 错误注入 | 预期三段式（发生了什么 / 为什么 / 下一步） | 实测 |
|---|---|---|---|
| C3-1 | 非管理员运行（Win32 5） | 「没有权限访问缓存驱动 / 控制设备仅允许管理员访问 / 右键以管理员身份运行」**不出现**"未加载"字样 | ☐ |
| C3-2 | 停服务后启动 UI（Win32 2/3） | 「未检测到缓存驱动 / 驱动未安装或未启动 / 运行安装向导」 | ☐ |
| C3-3 | 演示/注入 ATTACH 返回 170 | 通道 #8 转「降级·重试中」+ 开关「正在挂载…」；见 C5 | ☐ |
| C3-4 | 注入 ATTACH 返回 21 或 0x80000011 | 同上（三类瞬时码均可达触点） | ☐ |
| C3-5 | 模拟盘写失败后 FLUSH（0xC0000001） | 「数据尚未完全写入磁盘 / 磁盘报告写入错误 / 检查磁盘健康；未落盘数据仍在缓存中，可稍后重试」+ 重试按钮；**IRP 状态为失败**（T3 交叉） | ☐ |
| C3-6 | 协议 8（Win32 87） | 归因指引指向重装；**不得出现 0xC0000001** | ☐ |
| C3-7 | 自愈中点解除（0xC00000A3） | 按钮置灰 + 原因；已结算态显示「自愈已完成，无活跃错误」 | ☐ |
| **通过标准** | 每条均有可区分三段式 + 可点击动作；5 与 2/3 的文案与动作**不同** | | ☐ |
