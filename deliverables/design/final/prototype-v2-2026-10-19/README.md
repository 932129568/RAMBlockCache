## 1. 原型导航说明

### 1.1 打开方式

双击 `index.html`（或拖入任意现代浏览器）。无需服务器、无需联网。建议窗口 ≥1240×860（原型按 WPF 主窗口 1180×780 / min 900×600 等比绘制，含 1px 窗口描边与桌面投影）。

### 1.2 全局结构（自上而下）

| 区域 | 内容 | 对应 WPF |
|---|---|---|
| 标题栏 | 产品名 + **演示态切换**（原型专用走查工具，非产品 UI）+ **数据来源图例**按钮 + 窗口按钮 | `Window.Title`（标准 Chrome） |
| 四段状态条 | 驱动 / 挂栈 / 加速 / 风险；段点击路由：驱动→诊断、挂栈→加速、加速→状态、风险→应急（Phase 1 §T3.5 新映射） | `Controls/StateBar.xaml` |
| Banner | 异常的紧凑提示（完整三段式在状态页异常卡） | `MainWindow.xaml:52` Banner |
| 侧栏导航 | 六项固定顺序：状态 / 加速 / 收益 / 诊断 / 应急 / 设置；应急项异常时常驻高亮 + 徽标计数 | `MainWindow.xaml:58` 侧栏 + NavItemStyle |
| 内容区 | 六页单页切换（模拟 `SelectedPage` 机制） | `MainWindow.xaml` DataTrigger 切页 |
| 浮层 | 三段式确认弹窗 / Toast / 首次运行向导（560×480） | 弹窗 + `Views/FirstRunWizard.xaml` |

### 1.3 演示态切换（标题栏下拉，8 种）

| 演示态 | 走查目的 |
|---|---|
| 正常 | 六页正常态全量 |
| 熔断 · 自愈中 | 脉冲圆点（唯一两态之一）、解除熔断置灰 + 原因、异常卡三段式、应急页危险区 |
| 熔断 · 已结算 | 解除熔断可点、状态条/导航/卷卡文案一致性 |
| 安全模式 | 琥珀语义、退出安全模式确认流 |
| 未落盘超阈值 | 风险段琥珀 + 未落盘堆叠条 + 状态页异常卡 |
| 驱动离线 | 「正在重连…」脉冲、全界面「—」（禁显示 0）、诊断页降级自检 |
| 统计降级 | 骨架/「—」/不把过期值当正常数据 |
| 未挂栈（空态） | 空态即引导：状态页信息卡 + 运行首次向导主行动 |

### 1.4 交互提示

- 页面切换、弹窗、Toast、向导、配额滑块、写模式/预读下拉、挂载开关、L2/预取/回写配置、动效三选（**设置页「减少动效」当期生效**，可在原型内实时验证 reduced-motion 降级）均为可交互 mock。
- 「演示态」切换会触发加速页/状态页卷卡的 **FLIP 列表动画**（180ms）。
- 所有数值每 1 秒轻量抖动（对齐 StatsService 采样节奏；数字滚动 320ms 专用档）。
- 所有**危险操作**（一键熔断 / 退出安全模式 / 卸载 / 启用 L2 / 系统卷 opt-in）均走**三段式确认弹窗**（将发生什么 / 影响与风险 / 如何撤销），危险按钮不做默认焦点（焦点落在「取消」）。

## 5. 已知边界（移交 WPF 侧）

1. **响应式非目标**：原型按 1180×780 固定窗口绘制；WPF 侧按 02 §G.2 支持 1080p/2K + 125%/150% DPI 等比，布局不重排。
2. **无真机验证**：沙箱无交互桌面；所有动效/轮询/熔断流程需按新六页冒烟清单真机执行。
3. **mock 数据**：所有数值为演示用真实感序列（seeded），标注 `mock` 语义；接真数据后按 §3 图例逐项替换。
4. **演示态切换器**是原型走查工具，不进入 WPF（WPF 侧由真机冒烟清单的场景 A/B 覆盖）。
5. **主按钮配色**（04b §11.1 待拍板项）：本原型按规范建议值 `RbcAccent` 青 + `RbcTextOnAcent` 深墨绘制；若主理人改判深蓝，仅换 `--rbc-accent` 一族与 BtnPrimary 消费位。
