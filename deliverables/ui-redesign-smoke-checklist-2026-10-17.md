## I. WPF 与 02b 规范的已知偏差（备案）

| # | 偏差 | 原因 | 处置 |
|---|------|------|------|
| I1 | 数字无 tabular-nums 等宽 | WPF 无 CSS `font-variant-numeric` 等价物；Segoe UI 数字比例宽度 | 滚动期间单位/百分号与数值分离排版，把抖动限制在个位数；不阻塞 |
| I2 | 焦点环无淡入动画 | WPF `FocusVisualStyle` 模板不支持入场动画（瞬时出现） | 保留 2px 外环、始终可见（可访问性底线满足）；02b §B.3-11 的 120ms 淡入不做 |
| I3 | 骨架 shimmer 未接入 | 本期数据面全部同步可取（无加载等待态），无骨架使用场景 | 令牌与服务已建（RbcSkeleton/RbcSkeletonHighlight）；接入点随首个异步数据面出现时补 |
| I4 | Toast 服务无调用点 | W1-2「信任显性化」波次才接命令反馈 | 服务已就绪；E1 已列 |
| I5 | reduced-motion 自动检测口径 | `SystemParameters.ClientAreaAnimation` 只反映系统「菜单动画」类开关，与 Web `prefers-reduced-motion` 语义不完全等价 | 双通道兜底：系统开关 + 设置页手动覆盖（默认 auto） |
| I6 | 页面入场用 CubicEase 近似 | WPF KeySpline 在 XAML 模板内不可直接用静态资源曲线（代码侧 Motion 已用 Spline 精确复刻） | Toast 出入场用 CubicEase EaseOut/EaseIn 近似，误差在 02b 允许范围内 |
