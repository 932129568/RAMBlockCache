## 二、设计决策摘要

- **设计系统**：选定 **Linear（骨架）+ Tech Utility（视觉方向）**。理由：目标是 Windows 桌面控制台（WPF），Linear 式深色、低饱和、高信息密度的骨架最适合系统工具类产品；Tech Utility 视觉强调数据可读性与专业感，与驱动级缓存控制台的定位一致。
- **色彩令牌要点**：
  - 背景 `#0E0E11` / 卡片 `#17171C`（深色骨架，突出数据）
  - 强调色 `#4CC2FF`（品牌蓝，仅用于主行动与关键数据）
  - 语义五色：success / warning / danger / info / neutral，全站状态语义唯一（琥珀=风险、红=阻断、蓝=信息、绿=正常、灰=未就绪）
- **字体**：系统字体栈（Segoe UI 优先），**仅用字重 400（正文）/ 600（标题强调）** 两档，杜绝中黑体渲染不一致。
- **图表**：2 色系（品牌蓝 + 语义色点缀），全部内联 SVG + CSS/JS 手绘，不用 canvas 库；统计不可用一律显示「—」，禁止显示 0。
- **动效**：5 档时长梯度（约 120 / 180 / 240 / 320 / 480ms），统一缓动曲线，尊重 `prefers-reduced-motion`。

## 四、前后端联调要点速览

### 12 消息触点归属（一行表）

| # | 消息 | 主触点 |
|:-:|------|--------|
| 1 | GET_STATS | 状态首页三数字卡 + 收益页 + 状态条风险段（1s 轮询） |
| 2 | SET_CONFIG | 设置页（失败回滚，禁止乐观更新不回滚） |
| 3 | FLUSH | 卷卡「立即回写」+ 批量回写 + 卸载前自动 |
| 4 | GET_CONFIG | 设置页控件初值 + 诊断自检 |
| 5 | EXIT_SAFE_MODE | 应急页（二次确认后） |
| 6 | SET_VOLUME | 卷卡写模式下拉（失败回滚） |
| 7 | GET_VOLUMES | 加速页卷列表 + 首页卷卡 + 状态条（1s 轮询） |

| 9 | GET_LOG | 诊断页日志时间线（进入自动拉取） |
| 10 | GET_VERSION | 状态条驱动段 + 诊断自检（启动握手，硬校验协议号） |
| 11 | PANIC | 应急页熔断开关（三段式确认后） |
| 12 | PANIC_CLEAR | 应急页解除熔断（自愈完成后可点） |

### 六态判定优先级（一行说明）

自上而下命中即返回：**未安装 → 版本不匹配（阻断）→ 熔断·自愈中（子态）→ 熔断·全局透传 → 降级·安全模式 → 已安装未挂栈 → 就绪未加速 → 加速中·回写 → 加速中·直写**；规则 8（回写）先于 9（直写），全局状态条只要有回写卷即呈现回写语义。

### 错误码三段式原则

所有错误呈现必须含「**发生了什么 / 为什么 / 下一步做什么**」三段，且「下一步」必须是可点击动作；每个错误码全站唯一归属（`0xC0000001` 专属 FLUSH 失败、`0xC00000A3` 专属"自愈未完成被拒绝"、协议不匹配统一 Win32 87），禁止复用；瞬时错误（Win32 170/21、`0x80000011`）自动退避重试 ≤3 次（300/600/900ms）且可观测，确定性拒绝（Win32 5、负 NTSTATUS）立即失败不重试。

## 五、落地提示（原型 → WPF 实现）

| 原型概念 | WPF 对应 |
|----------|----------|
| CSS `:root` 设计令牌 | `ResourceDictionary`（`App.xaml` 合并字典，颜色/画刷/字号逐值对应） |
| 语义色令牌 | 命名画刷 `BrushSuccess/Warn/Danger/Info/Neutral`，禁止硬编码色值 |
| 深色骨架（背景/卡片/描边） | 控件模板 + `Style` 资源，暗色为唯一样式 |
| 状态条四段 / 卷卡六态徽标 | `ResolveUiState` / `ResolveVolumeState` 判定函数输出绑定（契约 §2 为唯一判定规则） |
| 三段式异常卡 | 用户控件 `AlertCard`，参数：严重度 / 三段文案 / 动作按钮集合 / 归因元信息折叠区 |
| 内联 SVG 图表 | `Path` + `StreamGeometry` 或自绘 `FrameworkElement`，数据源与统计卡同源 |
| 演示面板（demo 面板 / 演示态切换） | **仅供设计验收使用，不进生产代码**；生产状态一律来自 `AppState` 单一事实源 |
| 动效 5 档 | `Storyboard` / `VisualStateManager` 过渡时长，统一缓动；尊重系统「减少动态效果」设置 |
