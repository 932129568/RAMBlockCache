## 三、已修复的问题（附验证证据）

### 3.1 【核心】应用 DLL 入口点错报（微相信"无法定位程序输入点"×2）

**机制（实锤）**：元数据操作（改名/删除/TRIM）的钩子执行"刷脏 + 丢弃缓存视图"；在该窗口内，**在途读请求**（进入时盘面还是旧数据）完成下盘读后**回填进缓存** → 操作前盘面被重新提交 = 视图重污染 → 应用读到自己更新前的 DLL = 入口点错报。重启清空内核缓存 + MM 映像页才愈（解释"重启就好"）。

**修复**：视图世代门控（commit 校验世代）+ 变更窗（窗口内读写直通）+ 预取门控。

**验证**：
- A/B 对照：`gated=0`（修复前等价）→ **f_err=16 复现**；`gated=1`（修复后）→ **0 错误**
- 终验矩阵 mode0-5 全 clean；5/10 分钟长压零错误
- 核心回归 22/22；**ASan 全套件 22/22 零报告**

### 3.2 【核心】TRIM 处理丢已确认写（F9 级数据丢失窗口）

**机制**：TRIM 处理器顺序为 `flush → discard_all`；两者之间被吸收的**已确认写**（应用已收到 SUCCESS）随整卷丢弃。

**修复**：解析 TRIM 载荷，只失效被裁剪的范围（`RbTrimRangeInvalidate`），解析失败回退旧路径。

**验证**：mode3 忠实 TRIM 模型全 clean。

### 3.3 【配置】`CachePagingIo=0` 声明但从未实现

**机制**：配置表有此字段，读路径从不检查 → 分页 IO（加载器读 DLL、MM 回写）全程过缓存。

**修复**：`IRP_PAGING_IO` 且 `CachePagingIo=0` → 直通。

### 3.4 【前夜】注册表路径转义坏（三处）

**机制**：`L"\Registry\Machine\..."` 单反斜杠 → MSVC 丢反斜杠 → 路径损坏 → **ZwCreateKey 静默失败**。导致 ResumeLetters 记录/读取与 BOOTCFG 写持久化全部无声失效。

**修复**：`RB_REG_PARAMS` 上移 `rb_common.h` 共享，三处引用宏。

**验证**：重启后 attach D → 注册表出现 `ResumeLetters="D"`；BOOTCFG 写 1/写 0 往返，注册表跟随。

### 3.5 【功能】ResumeOnBoot 冷启动不执行

**机制**：恢复扫描（`RbAutoAttachSweep`）唯一执行体是 `Rb2Tick`（30s 周期线程），而 `Rb2Tick` 随特性层**惰性启动**（引擎创建时）→ 冷启动 + AutoAttach=0 时无人建引擎 → 扫描永不跑。

**修复**：`RbFeatInit()` 提前到 `DriverEntry` 尾部（CAS 幂等）。

**验证**：真机日志出现 `[561] resume list loaded`（DriverEntry 后 31s）。

### 3.6 【功能】ResumeOnBoot 被 boot-critical 静默跳过

**机制**：`D:\pagefile.sys`（64GB）使 `RbIsBootCriticalPdo(D)=TRUE`；扫查逻辑对此**静默 continue**（无日志），恢复永不发生。

**修复**：恢复模式（用户显式选择的字母）绕过该跳过，并加留痕日志；AutoAttach=1 全自动模式维持跳过。安全论证：恢复挂载发生在开机 30s 后（运行时挂栈，无引导路径）。

**状态**：已构建部署（245c6681），**待重启验证**。

### 3.7 【前端】C 盘无法手动加速

**机制**：驱动侧 54 号已放开系统卷，但前端 `canToggle = bound && !isSystem && !busy` 仍硬禁用。

**修复**：去掉 `!isSystem`，徽标与文案同步，确认框加系统卷风险提示。

### 3.8 【安装】AutoAttach 默认值与回滚脚本缺失

- 安装器默认写 `AutoAttach=1`（覆盖驱动默认 0）→ 改为 0
- 0x7B 一键回滚脚本只在 `src\scripts\`（目标机不存在）→ 随包安装
- GUI 过时文案、README 路径、脚本 CRLF
