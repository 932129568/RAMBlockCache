# 01 工具链安装：Visual Studio 2022 + WDK

RAMBoostFS 驱动需要 **Visual Studio 2022** 和 **Windows Driver Kit (WDK)** 才能编译。
以下是完整安装步骤（全部免费）。

## 1. 安装 Visual Studio 2022

1. 打开官网下载社区版（免费）：
   https://visualstudio.microsoft.com/zh-hans/downloads/
2. 运行安装器，勾选工作负载：
   - **使用 C++ 的桌面开发**（必选，含 MSVC 编译器）
   - 右侧"单个组件"里建议勾选 **Windows 11 SDK**（最新版即可）
3. 安装完成后**不要急着关**，保持默认路径。

> 如果电脑已装过 VS2022，直接跳到第 2 步；如装有其他版本（2019），
> 也请用 VS2022 确保与 WDK 26100 兼容。

## 2. 安装 Windows Driver Kit (WDK)

1. 打开 WDK 下载页（需要登录微软账户，免费）：
   https://learn.microsoft.com/en-us/windows-hardware/driver/download-the-wdk
2. 下载并运行 `wdksetup.exe`，一路下一步，保持默认路径
   （默认 `C:\Program Files (x86)\Windows Kits\10`）。
3. 安装器末尾会提示**安装 Visual Studio 扩展（VSIX）**——这一步**必须完成**，
   否则 VS 里没有"Windows 内核驱动"工具集。
   - 若自动跳转未弹出，可在 WDK 目录手动双击：
     `C:\Program Files (x86)\Windows Kits\10\Vsix\Microsoft.Windows.WDK.x64.vsix`

## 3. 验证安装

打开 **开始菜单 → "x64 Native Tools Command Prompt for VS 2022"**（开发者命令行），执行：

```bat
msbuild /version
```

能看到版本号即 OK。再执行：

```bat
where signtool
```

能看到 signtool.exe 路径（签名用）即 OK。

## 4. 常见问题

| 问题 | 解决 |
|---|---|
| 打开 .vcxproj 报"工具集 WindowsKernelModeDriver10.0 未安装" | 说明 VSIX 扩展没装好，重做第 2 步第 3 小点 |
| msbuild 提示找不到 | 用"开发者命令提示符"运行，或先执行 `VsDevCmd.bat` |
| 编译报缺 WDK 头文件 | 确认 WDK 与 SDK 版本 ≥ 10.0.22621（本项目面向 26100） |
| 磁盘空间 | VS+WDK 合计约需 15~20GB 空间 |
