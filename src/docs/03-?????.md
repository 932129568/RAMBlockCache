# 03 部署与使用

## 一、签名与测试模式（首次必做）

Windows 只允许加载有签名的内核驱动。RAMBoostFS 没有微软 WHQL 签名
（正式签名证书要花钱），所以走**自签名 + 测试签名模式**的免费路线：

```bat
scripts\sign_test.cmd      （管理员运行）
```

脚本会：生成自签名证书 → 签名 RAMBoostFS.sys → 开启测试签名模式。

> **必须重启电脑**，测试签名模式才生效。
> 若电脑开着 Secure Boot（安全启动），测试签名驱动无法加载，
> 需要进 BIOS 关闭 Secure Boot（详见 `05-签名与安全启动.md`）。

## 二、安装并启动驱动

```bat
scripts\install.cmd        （管理员运行）
```

> **⚠️ 当前不可用（如实标注）**：`scripts\install.cmd` 会调用 `install_auto2.ps1`，而后者已被标记废弃并在脚本开头无条件 `exit 1`（原因：旧脚本会把过滤驱动经错误路径引入引导卷，是 0x7B 事故根源）。因此该安装入口**当前无法使用**。
> 本包可用的安装入口为 `setup\ramboostsetup.ps1`（或 `setup\RamBoostSetup.exe`）：复制 .sys → 以 DEMAND_START 注册服务 → 按需运行时 attach 数据卷；**不写入卷类 UpperFilters**（避免 0x7B）。

验证是否加载成功：

```bat
fltmc
```
能看到 `RAMBoostFS` 实例、海拔 `373000.123456` 即成功。

## 四、命令行方式（可选）

```bat
ramboostctl status                查看统计（含 RMW 补读/余量整理次数）
ramboostctl get-config            查看配置
ramboostctl set size=16384 wb=1   改缓存为 16GB、开回写
ramboostctl set read=0            关读缓存
ramboostctl set vol=D:            只缓存 D 盘
ramboostctl flush                 立即回写
ramboostctl safe-mode             查看安全模式状态
ramboostctl safe-mode off         确认退出安全模式（恢复写缓存）
```

## 五、配置项说明

| 配置 | 默认 | 说明 |
|---|---|---|
| 总开关 | 开 | 关闭后全部 IO 直接放行，缓存停用 |
| 读缓存 | 开 | 命中直接内存返回；未命中整 4KB 子块读盘并缓存 |
| 写缓存 | 开 | 写入先进内存（标记脏），后台合并回写 |
| 回写模式 | 回写 | 回写=延迟落盘省 SSD 寿命；直写=立即落盘更保守 |
| 缓存大小 | 8192 MB | 建议 ≤ 物理内存一半（64G 机器可给 16~24G） |
| 回写周期 | 10 秒 | 后台线程周期；句柄关闭/Flush 始终立即回写 |
| 脏高水位 | 60% | 脏数据超过缓存上限 60% 触发强制回写 |
| 脏低水位 | 40% | 回写到 40% 为止 |
| 缓存系统卷 | 关 | 系统卷默认排除（最安全），可手动开启 |
| 盘符过滤 | 空 | 空=全部数据卷；系统卷是否参与看上一行 |

## 六、卸载

```bat
scripts\uninstall.cmd      （管理员运行）
```
脚本会先请求回写全部脏数据 → 卸载驱动 → 删除服务与文件。
