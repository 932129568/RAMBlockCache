## 3. 演示态用法（标题栏「演示态」下拉，共 12 态）

| 演示态 | 切换后预期看到什么 |
|--------|--------------------|
| 正常 | 默认态。设置页预设卡显示「自定义（基于：均衡）」——V2 基底数据 E: 为回写，即偏离均衡标称值（F1：手改受管项 → 自定义），差异条显示「每卷写模式：直写 → 回写」 |
| 熔断 · 自愈中 / 熔断 · 已结算 / 安全模式 / 未落盘超阈值 / 驱动离线 / 统计降级 / 未挂栈（空态） | V2 既有 7 态，行为不变 |
| 预设应用中 | 自动跳设置页：预设卡 Applying（不确定进度 + ComboBox disabled + 摘要表自动展开）→ 600ms 起摘要表逐行高亮（24ms 阶梯）→ 1500ms Applied「已应用『均衡 · 读写』预设」→ 再 900ms 应用性能档并弹 C-4 回写引导对话框（确认 = 性能档生效；取消 = 原子回滚均衡 + Toast「已取消回写开启，『性能 · 回写』预设未应用」） |
| 许可 · 试用中 | 自动跳设置页：许可卡试用中态（neutral 徽标「首发限免试用中」+ 剩余 23 天大值 + 「输入许可密钥」按钮 → 360px「激活通道」占位对话框） |
| 反作弊警示 | 自动弹 C-5 对话框（440 宽）：三段式 + 不再提示 + 「了解 EV 版」→ Toast「正式签名版下载页随官网发布提供」 |
| 二遍读对比 | 自动跳收益页：冷热对比卡直接结果态（第一遍 312 MB/s · 第二遍 3,180 MB/s · 提升 10.2× 徽标 + 纵向双条形）+ Toast「对比完成：第二遍快 10.2×」 |

**手动走查要点**：
- 冷热对比卡（收益页）：「选择文件」→ 文件路径对话框（默认 593 MB 示例；填 C: 路径会得到「所在卷尚未挂栈加速」行内错误）→ 「正在校验文件…」300ms → FileReady →「开始对比」→ 两遍运行（第一遍 1.6s 慢 / 第二遍 0.8s 快，进度与瞬时速度 250ms 刷新，可取消 → 回 FileReady + Toast「已取消，统计口径不受影响」）→ 结果态。卡片底部「演示开关」可展开勾选：降级横幅（含「第一遍可能不是冷读」）、首开骨架屏。
- 回写引导三触发点：① 加速页任一卷卡写模式下拉选「回写」② 设置页预设 ComboBox 选「性能 · 回写」③ 首次向导第 4 步选「性能 · 回写」再点下一步。**Esc / 点遮罩 / 取消按钮 = 取消（同口径）**：卷卡下拉回退直写，预设则整档原子回滚；勾选知情后点「开启回写」进入 Applying，此后的关闭不再回滚。
- 恢复默认（设置页预设卡）：点击 → 轻确认浮层（恢复说明 + [取消][恢复]），确认后才应用。
- 电源五态走查（设置页缓存策略卡底部「演示开关」select）：台式机 / 笔记本 87% / 低电量（C-4 确认禁用 + 「请接通电源后再开启回写」）/ 未知 / 读取中骨架；应急页未落盘核对卡标题行在有回写卷时常驻同款 chip。
- 三态骨架走查：预设卡 / 许可卡底部「演示开关」可模拟读取中（骨架）与读取失败（空态 + 重试）。
- 减少动效：设置页「预留与实验 → 减少动效」选「减少动效」后，对话框/进度/双条形 scaleY/骨架流光全部直显不闪。

## 4. 与 V2 的差异摘要

1. **信息架构**：设置页新增场景预设卡（首卡）与许可独立卡；收益页 bento 重排（行1 = 冷热对比 + 命中率趋势，其余顺延）；首次向导四步 → 五步（选卷后并入选预设）。
2. **弹窗体系**：新增对话框基座（560/480/440/360 四档宽、0.98 微缩放入场、#9E000000 遮罩贴窗口内）；V2 三段式确认弹窗迁移至基座，用法（openModal）与行为不变。
3. **新增组件**：C-1~C-7 七件（预设卡/来源 chip/对比卡/回写引导/反作弊警示/许可卡/电源 chip），全部复用 V2 令牌，零新增色值；仅新增 3 个度量/动效令牌（N-1~N-3）。
4. **演示态**：8 态 → 12 态（+预设应用中 / +许可试用中 / +反作弊警示 / +二遍读对比）。
5. **修正**：默认预设档位由「均衡」改为按卷实况推导——V2 基底数据 E: 为回写模式，按 F1「手改任一受管字段即偏离」应显示「自定义（基于：均衡）」，消除「预设卡说直写、卷卡却回写」的矛盾；切回直写且无其他偏离时自动回到标称档。
6. **修正轮（Phase 4 审查后）**：C-2 flash 高亮移除（回归 C-2.4 裁定）；C-3 双条形回归 06 C-3.2 纵向形态并以 scaleY 生长（红线 6）；C-3 交互流补 Validating→FileReady 与空态「开始对比」；C-4 宽 560→480；遮罩 fixed→absolute；恢复默认补轻确认；许可已激活态改文本型大值、激活占位改 360px 对话框；应急页补电源 chip；各组件三态（骨架/空态）补齐；文案批量对齐 06 白名单。

## 7. 红线与 Anti-Slop 自查结论

零外部资源（唯一 data-URI 为 V2 既有的 select 下拉箭头内联 SVG）；JS `node --check` 通过 +
DOM-stub harness 实跑（对话框开关 / 向导五步 / benchmark / anticheat / 预设全流 / **修正轮
48 项断言全过**）无异常；**红线 6 复扫零命中**（`transition:width|height|margin|top|left` = 0，
双条形改 scaleY）；reduced-motion 全分支覆盖（对话框直显、进度静态、双条形 scaleY 终态、
骨架流光停止）；文案守 I-08（禁「秒变 SSD」类表述；冷热口径统一「第一遍 = 盘速 /
第二遍 = 缓存速」；术语白名单内）；accent 不表达状态（状态一律语义五色；预设档位条为
配置身份，R-1 已裁定）。
